# Phase 10 — implementation delivery and remaining operational acceptance

15 November 2026. Tools and governance procedures have been implemented. Final
regression results are recorded below and in phase10-acceptance.json. The real
scheduled GitHub → SiteGround acceptance remains open; this report does not
claim an automatic run from synthetic fixtures or manually invoked commands.

## Delivered

- Read-only `scripts.quality_report` reuses the existing entry/taxonomy/layer
  validators and the canonical complete generated-data inventory. It compares
  3,345 generated files, including OpenAPI, licence and manifest, refuses
  ambiguous/missing/nonregular inputs, and checks input stability at the end.
  The actual corpus has 3,336 entries and no generated-data discrepancies.
- `scripts.check_operational_cycle` strictly correlates supplied run/job gates,
  acquisition base/tested tree, changed or unchanged snapshot, reviewed scheduled
  host command, publisher/active token and HTTPS release. It distinguishes
  failure, missing evidence, changed publication and no-change. It authenticates
  neither origin nor truth of supplied captures; retained original evidence needs
  independent operator review.
- Issue and PR templates, source-admission/contribution guidance, explicit review
  roles/decisions, correction rules and operational recovery procedures are in
  quality-governance.md and operations-governance.md. Missing optional metadata
  does not invent evidence; changes are corrected in their responsible layer.
- The existing GitHub workflow runs the read-only quality gate after building and
  before full tests/publication. Weekly scheduling, permissions, acquisition-base
  checks and non-force publication remain unchanged. No new host scheduler,
  background service, notification or automatic repair was installed.
  Base/candidate tree hashes, change result and published commit are recorded in
  the corresponding job logs for later correlation. The quality gate's full JSON
  is temporary on the runner; only its summary is printed to retained job logs.
  No permanent Actions artifact retention is claimed.

## Independent adversarial review

Three delegated agents implemented/reviewed quality, operations and independent
false-green probes. The review produced 17 permanent independent tests. Reproduced
and corrected problems included incomplete schema coverage, omitted generated
manifest/OpenAPI/licence checks, ambiguous input keys, arbitrary publisher-command
hashes, failed or malformed evidence masked by absent sections, and completed
jobs with unfinished steps. Final targeted tests cover those regressions, layer
separation, source-membership provenance, duplicate identities, symlinks, invalid
confidence, projection drift, no-change evidence and failure exit codes.

The taxonomy gate remains effective under `python -O`. Shared generation was
extracted from the existing writer without changing generated byte formats; the
real inventory comparison verifies the checked-in outputs remain identical.
