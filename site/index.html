01

Description

The community documents living-off-the-land techniques across a dozen separate catalogues — each with its own format, taxonomy, and search. loldex unifies them into one normalized index you can pivot across by platform, kill-chain phase, required privilege, and capability — the query a red teamer actually runs on an engagement.

03

What makes it different

The pivot is cross-domain. You're a domain user on a Windows box, in an AD with reachable Linux servers — loldex shows everything you can do, regardless of platform. That's the query no existing tool answers at the entry level.

04

Contributing

We don't re-catalogue what upstream projects already document — we unify, enrich, and cross-link it. Here's where you can help.

  • adaptersWrite an adapter for a new source. The highest-value contribution — one adapter adds an entire catalogue via automated sync.
  • ad curationNormalize Active Directory techniques. Upstream AD data is prose markdown; turning it into structured entries needs a human who knows the attack paths.
  • enrichmentAdd opsec, detection, and ATT&CK mappings. The value-add fields the source catalogues don't carry.
  • accessImprove search, the API, and the CLI. The layers operators actually reach the index through.
  • sourcesFlag a missing source. Structured data, redistributable licence, unit = "legitimate tool abused." That's the bar.
