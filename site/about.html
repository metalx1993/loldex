LOLDEX brings public living-off-the-land research across Linux, Windows and Active Directory into a searchable knowledge index.

Built on community research

We aggregate and attribute existing research. Source data, our interpretation and public fields remain separate. Each claim keeps its own provenance and confidence.

  • GTFOBins — Linux binaries
  • LOLBAS — Windows binaries, libraries and scripts
  • LOLDrivers — Windows drivers
  • LOLAD — Active Directory techniques
  • WADComs — Windows and Active Directory commands

Read confidence claim by claim

An upstream statement, a deterministic adapter mapping and a heuristic inference are different kinds of evidence. A high-confidence claim does not raise the confidence of other claims on the same entry.

Relationships are derived from those claims. They do not declare that tools are equivalent or that one technique causes another.

Observation is not a clock

Entries without an observation are marked “Not observed.” A reliable presence observation describes what the source produced during that cycle. It does not promise that a technique works today. A stale candidate is not an automatic removal decision.

ATT&CK attribution

Technique names, descriptions and tactics are drawn from a pinned MITRE ATT&CK Enterprise snapshot. Registry metadata identifies a technique; it does not validate the individual entry claims. Original catalogue data remains under each upstream project's license.
